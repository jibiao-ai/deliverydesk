DeliveryDesk 前端开发规范
========================================

一、技术栈
----------------------------------------
框架:       React 18.3 (函数组件 + Hooks, 无 class 组件)
构建:       Vite 5.x
样式:       Tailwind CSS 3.4 + CSS Variables (无 CSS Modules, 无 styled-components)
状态管理:   Zustand 4.5 (单一 store, 无 Redux/Context)
路由:       React Router DOM 6.26 (仅 App.jsx 中定义, 页面切换由 Zustand activePage 驱动)
HTTP:       Axios 1.7 (全局实例, 拦截器自动处理 token/401)
图标:       Lucide React 0.424 (全部从 lucide-react 导入, 不用其他图标库)
图表:       Recharts 3.9
通知:       React Hot Toast 2.4 (toast.success / toast.error)
Markdown:   React Markdown 9.0 + Highlight.js 11.10
流程图:     @xyflow/react 12.11 (仅 WorkflowPage 使用)


二、目录结构
----------------------------------------
src/
  main.jsx                  入口, ReactDOM.createRoot
  App.jsx                   路由定义: /login + /* -> PrivateRoute -> MainLayout
  store/useStore.js          Zustand store (auth/sidebar/theme/agents/conversations)
  services/api.js            Axios 实例 + 所有 API 函数 (集中管理)
  styles/index.css           Tailwind base + CSS Variables + 暗色模式全局覆盖
  components/
    MainLayout.jsx           顶栏 + 页面路由表 (pageComponents/PAGE_META/ADMIN_PAGES)
    Sidebar.jsx              侧边栏 (userMenuGroups + adminMenuGroups 分组)
    FullscreenButton.jsx     全屏切换按钮
  pages/
    XxxPage.jsx              每个功能一个页面文件, 默认导出
  data/
    motivationalQuotes.js    静态数据文件


三、页面注册流程 (新增页面必做4步)
----------------------------------------
1. services/api.js        添加 API 函数
2. pages/XxxPage.jsx      创建页面组件 (export default function XxxPage)
3. components/Sidebar.jsx  添加菜单项:
   - 顶部 import 图标
   - 在 userMenuGroups 或 adminMenuGroups 对应组的 items 中添加:
     { id: 'xxx', label: '页面名称', icon: IconName }
4. components/MainLayout.jsx 注册:
   - import XxxPage from '../pages/XxxPage'
   - pageComponents 添加: 'xxx': XxxPage
   - PAGE_META 添加: 'xxx': { title: '页面名称', subtitle: '页面描述' }
   - 如需管理员权限: ADMIN_PAGES.add('xxx')


四、页面组件编写规范
----------------------------------------

4.1 文件头部 import 顺序:
   1. React 及 hooks (useState, useEffect, useCallback, useRef)
   2. Lucide 图标 (花括号解构)
   3. Recharts 组件 (如需图表)
   4. API 函数 (from '../services/api')
   5. Store (from '../store/useStore')
   6. 其他 (toast, FullscreenButton 等)

4.2 暗色模式必须支持:
   const theme = useStore((s) => s.theme);
   const isDark = theme === 'dark';

4.3 通用样式变量 (每个页面顶部定义):
   const cardClass = `rounded-xl border ${isDark ? 'bg-slate-800 border-slate-700' : 'bg-white border-gray-200'}`;
   const textMain = isDark ? 'text-slate-200' : 'text-gray-800';
   const textSub = isDark ? 'text-slate-400' : 'text-gray-500';
   const textMuted = isDark ? 'text-slate-500' : 'text-gray-400';

4.4 数据加载模式:
   const [loading, setLoading] = useState(false);
   const [data, setData] = useState([]);

   const loadData = useCallback(async () => {
     setLoading(true);
     try {
       const res = await getXxxList({ ... });
       if (res?.code === 0) setData(res.data || []);
     } catch (e) { console.error(e); }
     finally { setLoading(false); }
   }, [依赖项]);

   useEffect(() => { loadData(); }, [loadData]);

4.5 页面根元素:
   <div className="h-full overflow-y-auto p-6 space-y-5">
     ...
   </div>


五、API 层规范 (services/api.js)
----------------------------------------

5.1 Axios 实例配置:
   baseURL = '/api'
   timeout = 120000 (2分钟)
   Content-Type = 'application/json'

5.2 拦截器:
   请求: 自动从 localStorage 读取 token, 附加 Authorization: Bearer xxx
   响应: 自动解包 response.data; 401 自动清除 token 并跳转 /login

5.3 函数命名规范:
   查询列表:  export const getXxxList = (params) => api.get('/xxx/list', { params });
   查询详情:  export const getXxx = (id) => api.get(`/xxx/${id}`);
   创建:      export const createXxx = (data) => api.post('/xxx', data);
   更新:      export const updateXxx = (id, data) => api.put(`/xxx/${id}`, data);
   删除:      export const deleteXxx = (id) => api.delete(`/xxx/${id}`);
   统计:      export const getXxxStats = (params) => api.get('/xxx/stats', { params });

5.4 文件上传:
   export const uploadXxxFile = (file, extraParam) => {
     const fd = new FormData();
     fd.append('file', file);
     if (extraParam) fd.append('param_name', extraParam);
     return api.post('/xxx/upload', fd, {
       headers: { 'Content-Type': 'multipart/form-data' },
     });
   };

5.5 响应格式约定:
   成功:     { code: 0, data: ..., message: 'success' }
   列表:     { code: 0, data: [...], total: 120, page: 1 }
   失败:     { code: -1, message: '错误信息' }
   前端判断: if (res?.code === 0) { ... }


六、暗色模式规范
----------------------------------------

6.1 实现方式:
   - Zustand 管理 theme 状态 ('light' | 'dark'), 持久化到 localStorage
   - document.documentElement.setAttribute('data-theme', theme) 切换
   - tailwind.config.js: darkMode: ['selector', '[data-theme="dark"]']
   - 不使用 Tailwind dark: prefix, 用 isDark 三元运算符

6.2 配色对照:
   用途         Light                    Dark
   主背景       bg-gray-50 / #ffffff     bg-slate-900 / #0f172a
   卡片         bg-white                 bg-slate-800 / #1e293b
   悬停         bg-gray-100              bg-slate-700 / #334155
   主文字       text-gray-800 / #111827  text-slate-200 / #f1f5f9
   副文字       text-gray-500 / #6b7280  text-slate-400 / #94a3b8
   淡文字       text-gray-400 / #9ca3af  text-slate-500 / #64748b
   边框         border-gray-200          border-slate-700 / #334155
   输入框背景   bg-white                 bg-slate-700

6.3 写法示例:
   className={`px-3 py-2 rounded-lg border ${
     isDark ? 'bg-slate-700 border-slate-600 text-slate-200'
            : 'bg-white border-gray-300 text-gray-700'
   }`}

6.4 全局 CSS 覆盖 (index.css):
   对 .bg-white, .text-gray-xxx, .border-gray-xxx 等 Tailwind 类
   在 [data-theme="dark"] 下用 !important 全局替换
   对半透明背景 (.bg-white/70) 也有对应覆盖


七、组件模式规范
----------------------------------------

7.1 自定义下拉框 CustomSelect (禁用原生 <select>):
   - 用 useState 控制 open 状态
   - 用 useRef + mousedown 事件实现点击外部关闭
   - ChevronDown 图标带 rotate-180 旋转动画
   - 选中项显示 Check 图标 + font-medium
   - 下拉面板: absolute z-50, backdrop-blur-xl, max-h-60 overflow-y-auto
   - options 格式: [{ value: '', label: '全部' }, { value: 'x', label: 'X' }]
   - 必须传 isDark 支持暗色

7.2 删除确认弹窗 (禁用 window.confirm):
   状态:
     const [deleteTarget, setDeleteTarget] = useState(null);
     const [deleting, setDeleting] = useState(false);
   触发: onClick={() => setDeleteTarget(item)}
   布局:
     - 全屏遮罩: fixed inset-0 bg-black/40 backdrop-blur-sm z-50
     - 弹窗: rounded-2xl shadow-2xl w-full max-w-sm, 点击遮罩关闭 (deleting 时禁止)
     - 顶部: h-1 红色渐变条 (from-red-400 via-red-500 to-red-600)
     - 图标: AlertTriangle, w-14 h-14 圆形背景
     - 按钮: 取消(灰) + 确认删除(红, 带 Loader2 loading 态)
     - e.stopPropagation() 阻止弹窗内点击冒泡

7.3 毛玻璃卡片 GlassCard:
   className="rounded-2xl border border-white/40 bg-white/70 backdrop-blur-xl shadow-lg"
   hover 态: hover:shadow-xl hover:border-primary-200/60

7.4 状态徽章 StatusBadge:
   className="inline-flex items-center gap-1 px-2 py-0.5 text-xs font-medium rounded-full border"
   颜色变体: bg-green-100 text-green-700 / bg-amber-100 text-amber-700 / bg-red-100 text-red-700

7.5 Tab 切换:
   容器: flex rounded-lg border
   按钮: flex items-center gap-1.5 px-3 py-1.5 text-sm
   激活态: bg-primary-600 text-white
   非激活: isDark ? 'text-slate-300 hover:bg-slate-700' : 'text-gray-600 hover:bg-gray-50'
   首末按钮加 rounded-l-lg / rounded-r-lg

7.6 搜索输入框:
   <div className="relative">
     <Search className="absolute left-3 top-1/2 -translate-y-1/2 w-4 h-4" />
     <input className="w-full pl-9 pr-3 py-1.5 text-sm rounded-lg border" placeholder="搜索..." />
   </div>

7.7 上传区域:
   拖拽框: border-2 border-dashed rounded-xl, h-32
   上传中: RefreshCw animate-spin
   结果: 成功绿 bg-green-50 / 失败红 bg-red-50 (暗色模式 bg-green-900/30 / bg-red-900/30)

7.8 分页:
   <div className="flex items-center justify-between px-4 py-3 border-t">
     <span className="text-xs">第 X 页 / 共 N 页</span>
     <div className="flex gap-2">
       <button disabled={page<=1}>上一页</button>
       <button disabled={page>=maxPage}>下一页</button>
     </div>
   </div>


八、图表规范 (Recharts)
----------------------------------------

九、设计规范
----------------------------------------

9.1 品牌色:
   Primary: #513CC8 (深紫), 梯度 50-900 在 tailwind.config.js 定义
   Success: #00B894    Warning: #FDCB6E
   Danger:  #E17055    Info:    #0984E3

9.2 圆角:
   卡片: rounded-xl (12px)
   弹窗: rounded-2xl (16px)
   按钮: rounded-lg (8px) 或 rounded-xl (12px)
   输入框: rounded-lg (8px)
   头像: rounded-full
   徽章: rounded-full

9.3 字号:
   页面标题: text-lg font-semibold (顶栏 h1)
   卡片标题: text-sm font-semibold
   正文:     text-sm
   辅助:     text-xs
   KPI数值:  text-xl font-bold 或 text-2xl font-bold

9.4 间距:
   页面:     p-6
   卡片内:   p-4
   紧凑卡片: p-3
   弹窗:     p-6
   元素间:   gap-3 或 space-y-4
   图标与文字: gap-2

9.5 阴影:
   卡片:     shadow-sm 或无
   悬浮卡片: shadow-lg
   弹窗:     shadow-2xl
   下拉面板: shadow-xl

9.6 过渡动画:
   通用: transition-colors 或 transition-all
   持续: duration-200 或 duration-300
   旋转: transition-transform (ChevronDown rotate-180)
   加载: animate-spin (RefreshCw, Loader2)
   脉冲: animate-pulse (未读通知红点)

9.7 z-index 层级:
   普通弹出层 (下拉框): z-50
   模态弹窗:           z-50 (配合 fixed inset-0 遮罩)
   通知下拉:           z-50

9.8 图标规格:
   行内小图标: w-3.5 h-3.5
   按钮图标:   w-4 h-4
   卡片图标:   w-5 h-5 或 w-4 h-4
   空状态图标: w-10 h-10 或 w-16 h-16
   弹窗主图标: w-7 h-7 (w-14 h-14 圆形背景)


十、Zustand Store 规范
----------------------------------------

10.1 结构 (单一 store):
   auth:    user, token, setAuth(), logout()
   sidebar: sidebarCollapsed, toggleSidebar()
   page:    activePage, setActivePage()
   theme:   theme, setTheme()
   chat:    agents, selectedAgent, conversations, currentConversation, messages, isSending

10.2 读取: const xxx = useStore((s) => s.xxx);
   不要解构整个 store, 按需选择字段

10.3 持久化:
   token -> localStorage.token
   user  -> localStorage.user (JSON)
   theme -> localStorage.theme


十一、Toast 通知规范
----------------------------------------
成功: toast.success('操作成功')
失败: toast.error(res.message || '操作失败')
位置: App.jsx 中 <Toaster position="top-center" />


十二、禁止事项
----------------------------------------
1. 禁止使用原生 <select>, 必须用 CustomSelect 自定义下拉框
2. 禁止使用 window.confirm() / window.alert(), 必须用自定义 Modal
3. 禁止使用 Tailwind dark: prefix, 用 isDark 三元运算符
4. 禁止直接操作 DOM (除非注入动画 style 标签)
5. 禁止在页面组件中直接使用 fetch, 统一走 services/api.js 的 Axios 实例
6. 禁止使用 class 组件, 全部用函数组件 + Hooks
7. 禁止在 Axios 之外手动处理 401 跳转
8. 禁止硬编码 API 路径前缀, 统一用 api 实例 (baseURL = '/api')
